DEPLOYMENT ON GITHUB:
---------------------
1. Extract this zip file or upload all files to your GitHub repository root.
2. Place your video file `96116.mp4` into the root directory alongside `index.html` (or in `assets/` and update the video path).
3. Go to GitHub Repository Settings:
   - Navigate to "Pages" (under Code and automation).
   - Source: "Deploy from a branch".
   - Branch: "main" (or "master"), Folder: "/ (root)".
   - Click "Save".
4. Custom Domain Setup (Optional):
   - In GitHub Pages settings under "Custom domain", verify your domain (e.g. firecutdiamonds.com).
   - Update your DNS records with your registrar (Point A records to GitHub Pages IPs or CNAME to <username>.github.io).
