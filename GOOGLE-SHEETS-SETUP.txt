FIRECUT INQUIRY → GOOGLE SHEETS

1. Create a Google Sheet.
2. Open Extensions → Apps Script.
3. Paste google-apps-script.gs and save.
4. Deploy → New deployment → Web app.
5. Execute as: Me. Who has access: Anyone.
6. Copy the Web app URL ending in /exec.
7. The supplied inquiry.js is already connected to your deployed /exec URL.
8. Upload the complete website to GitHub, keeping inquiry.js in the repository root.
9. Submit one test inquiry. A tab named Inquiries will be created automatically and the submission will appear there.

Do not put payment credentials, OTPs, PINs or card authentication data into this form.
